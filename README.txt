GERİ DÖNMEYENLER — Guía de Despliegue y Publicación
===================================================

1. Requisitos:
   - Un servicio de hosting estático (Netlify, Vercel, GitHub Pages, cPanel, Hostinger, etc.).

2. Pasos para publicar:
   - Descomprime el archivo `index.zip` para obtener el archivo `index.html`.
   - Sube dicho archivo a la raíz de tu servidor web.

3. Acceso al Panel de Administración:
   - Entra en tu sitio web publicado, desplázate hasta el pie de página (footer) y haz clic en "Acceso Autor".
   - Introduce la clave de acceso por defecto: 1922-1959
   - Desde allí podrás gestionar capítulos, traducciones, portadas y exportar/importar copias de seguridad en formato JSON.
